# Customer Churn Analytics & AI Prediction

## Overview
An end-to-end Data Analytics and AI project that analyzes customer churn and predicts whether a customer may leave a service.

## Features
- Data preparation and missing-value handling
- Exploratory Data Analysis
- Data visualization
- Random Forest machine-learning prediction
- Accuracy, precision, recall and F1 evaluation
- Feature-importance analysis

## Dataset
The program generates a reproducible synthetic dataset of 1,200 customer records. Synthetic data is used for demonstration so no private customer information is required.

## Run
1. Install Python 3.9+.
2. Open a terminal in this project folder.
3. Run:
   `pip install -r requirements.txt`
4. Run:
   `python customer_churn_analysis.py`

The `output` folder will contain the generated dataset, metrics and charts.

## AI Model
Random Forest Classifier with preprocessing through a scikit-learn pipeline.

## Business Use
A real organization could use a similar workflow to identify higher-risk customers and prioritize retention activities.

## Limitation
This internship demonstration uses synthetic data. A production system would require validated real-world data, privacy controls, monitoring and regular retraining.
